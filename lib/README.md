# Lib Folder

This folder is for utility functions, constants, and helper modules that are used across the application.

## Suggested Usage

- **API clients**: Functions for making API calls
- **Utilities**: Date formatting, string manipulation, etc.
- **Constants**: Application-wide constants
- **Validators**: Form validation functions
- **Helpers**: Reusable helper functions

## Example Structure

```
lib/
├── api/
│   └── client.ts
├── utils/
│   ├── date.ts
│   └── format.ts
└── constants.ts
```
